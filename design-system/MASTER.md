## 2. Style

**Primary style: Minimal Professional**
- Clean white/near-black contrast
- Generous whitespace with intentional section rhythm
- No glassmorphism, no heavy shadows, no clay effects
- Subtle stroke borders (`#d9d9d9`) as separators
- Accent via bold yellow CTA (`#fdc115`) only — not decorative
- Typography-first hierarchy (size + weight, not color blocks)

**Secondary motif: Editorial Grid**
- Content laid out in deliberate columns (Bootstrap 12-col)
- Section labels in small caps/medium weight before headings
- Numbered feature blocks for scannable structure

## 3. Color Tokens

All colors must be referenced via CSS custom properties — never raw hex in components.

```css
:root {
  /* Brand */
  --primary:      #fdc115;   /* Golden Yellow — CTAs, highlights */
  --secondary:    #1b1b1b;   /* Near Black — surfaces, reverse sections */

  /* Text */
  --text:         #000000;   /* Primary body / heading text */
  --color2:       #6a6a6a;   /* Secondary / muted text */

  /* Backgrounds */
  --white:        #ffffff;   /* Default surface */
  --color1:       #f6f6f6;   /* Alternate light section BG */
  --color6:       #e4edf9;   /* Soft blue tint BG */
  --color9:       #fff6db;   /* Warm yellow tint BG */

  /* Semantic */
  --color3:       #34a852;   /* Success / Google GMB green */
  --color5:       #ea4334;   /* Error / destructive */
  --color4:       #3f2fee;   /* Accent violet (use sparingly) */
  --color8:       #2567e8;   /* Link / form CTA blue */
  --color7:       #ba77eb;   /* Decorative purple (use sparingly) */

  /* UI Chrome */
  --stroke:       #d9d9d9;   /* Borders, dividers */
  --lead-form-confi: #c6fdbd; /* Confidentiality badge BG */
  --admin-primary: #009cff;  /* Admin panel accent */
}
```

### Contrast Pairs (WCAG AA)

| Foreground | Background | Ratio | Use |
|-----------|-----------|-------|-----|
| `#000000` | `#ffffff` | 21:1 | Body text |
| `#000000` | `#f6f6f6` | ~18:1 | Alt section text |
| `#1b1b1b` | `#fdc115` | ~8:1 | Button label on primary |
| `#ffffff` | `#1b1b1b` | ~17:1 | Reverse section text |
| `#6a6a6a` | `#ffffff` | ~5.7:1 | Muted text (passes AA) |
| `#2567e8` | `#ffffff` | ~4.6:1 | Link color (passes AA) |

## 4. Typography

**Font family:** Neue Haas Display (local woff2 — no Google Fonts fallback needed)
- Weight 400 → Roman (body, descriptions)
- Weight 500 → Medium (labels, nav, UI text)
- Weight 600 → Bold (headings, hero)

```css
/* Type scale */
--text-xs:   12px;   /* Fine print, badges */
--text-sm:   14px;   /* Captions, helper text */
--text-base: 16px;   /* Body paragraphs */
--text-md:   18px;   /* Lead text, FAQ body */
--text-lg:   20px;   /* Accordion questions */
--text-xl:   22px;   /* Sub-headings */
--text-2xl:  26px;   /* Section descriptors */
--text-3xl:  32px;   /* H3 headings */
--text-4xl:  38px;   /* H2 mobile */
--text-5xl:  52px;   /* H2 desktop */
--text-6xl:  56px;   /* H1 service pages */
```

**Line heights:**
- Body (≤18px): `1.5`
- Subheadings (20–26px): `1.4`
- Headings (≥32px): `1.2–1.3`
- Hero large (52–56px): `68px` explicit (matches `.testimonial-heading`)

**Responsive scaling:**
- H1/H2 at 52–56px desktop → 38–42px tablet → 36px mobile
- Body stays 16–18px across all breakpoints (no auto-zoom risk)
- Minimum body font: **16px** (avoids iOS input zoom)

## 5. Spacing System

4pt base grid. Use multiples of 4 or 8.

```
4px   → micro gap (icon to text)
8px   → tight component gap
12px  → input padding, small card gap
16px  → standard component padding
20px  → mobile section horizontal inset
24px  → card internal padding
28px  → lead form padding
32px  → heading margin-bottom
40px  → section vertical margin (mobile)
48px  → large component gap
60px  → desktop sidebar/right padding
70px  → section margin-bottom (desktop, .margin-box)
100px → desktop horizontal page inset
180px → hero top padding (accounts for fixed navbar)
```

## 6. Layout & Responsive

**Framework:** Bootstrap 5 grid (12 columns)
**Max-width:** Controlled by Bootstrap container + 100px horizontal padding at desktop

| Breakpoint | Width | Horizontal Inset |
|-----------|-------|-----------------|
| Mobile (xs) | < 576px | 20px |
| Tablet (sm–md) | 576–991px | 40px |
| Desktop (lg) | 992–1199px | 30px |
| Large (xl) | 1200–1399px | 40–50px |
| XL (xxl) | ≥ 1400px | 100px |

**Rules:**
- Mobile-first: stack columns on xs, switch to side-by-side at `lg`
- Never disable zoom (`maximum-scale=1` is forbidden)
- No horizontal scroll on any breakpoint
- Use `min-h-dvh` (or equivalent) for full-viewport hero sections
- Fixed navbar: hero content starts at `padding-top: 180px`
- Bottom safe area: account for mobile browser chrome

## 7. Components

### Button (`.buttons`)
- Shape: `border-radius: 60px` (pill)
- Padding: `15px 22px` desktop / `16px 20px` mobile
- Background: `var(--primary)` (#fdc115)
- Text: `var(--white)`, `font-weight: 400`
- Icon: 20×20px white circle with black arrow, animated on hover
- Hover animation: icon slides out top-right, copy slides in from bottom-left (duration 300ms, ease-in-out)
- Min touch target: 44px height (met by padding)
- Border: `1px solid var(--primary)` (matches BG — enables ghost variant by swapping fill)

### CTA Hierarchy
- **Primary:** `--primary` pill button (one per section max)
- **Secondary:** outline or text link variant
- **Destructive:** `--color5` (#ea4334), spatially separated

### Accordion (FAQs)
- No border (`--bs-accordion-border-width: none`)
- Button BG: transparent; text: `--text` (collapsed) / `--color2` (open)
- Font: 20px / weight 500
- Body: 18px / weight 500 / line-height 1.5
- Divider: `border-bottom: 1px solid var(--stroke)`
- Animation: 500ms ease-in-out (bootstrap chevron rotation)

### Lead Form Card
- Container: `border-radius: 16px`, `border: 1px solid var(--stroke)`, `padding: 24px 28px`
- Labels: 15px / weight 500
- Inputs: `padding: 12px`, placeholder 14px
- Submit: BG `--color8` (#2567e8), `border-radius: 10px`, 16px / weight 500
- Confidentiality badge: `--lead-form-confi` BG, green icon, 14px / weight 500

### Navigation
- Fixed position (triggers `padding-top: 180px` on hero)
- Primary nav: horizontal top bar (desktop) / mobile hamburger
- Max 5 primary items
- Active state: visually distinct (color or underline indicator)

## 8. Animation & Motion

| Type | Duration | Easing |
|------|----------|--------|
| Button icon hover | 300ms | ease-in-out |
| Button copy enter | 300ms + 100ms delay | ease-in-out |
| Accordion expand/collapse | 500ms | ease-in-out |
| Page loader | system-defined | — |
| Smooth scroll | Lenis (continuous) | spring-based |
| Section entrance | 150–300ms | ease-out |

**Rules:**
- Animate `transform` and `opacity` only — never `width`, `height`, `top`, `left`
- Respect `prefers-reduced-motion` — disable or minimize all non-essential motion
- Max 1–2 animated elements per view
- Loading exceeding 300ms → skeleton or Lottie loader (`.Loader` component exists)

## 9. Imagery & Icons

**Images:**
- Format: WebP (`.webp`) for all photography — already in use
- Lazy load below-fold images (`loading="lazy"` or Next.js `Image` default)
- Always set `width` + `height` or `fill` + aspect container to prevent CLS
- Alt text required on all `<Image>` components (meaningful, not decorative)

**Icons:**
- Library: `react-icons` (fa6 subset — `FaArrowRight`, `FaArrowDown`, etc.)
- Style: consistent stroke/fill within a single visual layer
- No emojis as structural icons
- Touch target: minimum 44×44px (use padding/hitSlop if icon is smaller)
- SVG icons only — no PNG icon sprites

**Videos:**
- Format: MP4 (`/video/seo-video.mp4`, `/video/web-design.mp4`)
- Lazy load or `preload="none"` for below-fold video
- Provide poster image to prevent layout shift

## 10. Forms & Feedback

- Visible label per input (`<label for="">` — not placeholder-only)
- Inline validation on blur (not on keystroke)
- Error message: below the related field, 14px, `--color5`
- Required fields: marked with asterisk or label suffix
- Submit button: disabled + spinner during async (`.loading-buttons` pattern)
- Toast / success: auto-dismiss 3–5s, `aria-live="polite"`
- Confirmation before destructive actions (confirmation dialog)
- ReCAPTCHA: present, `z-index: 999`, mobile scale 0.92

---

## 11. SEO & Metadata

- `<title>` and `<meta description>` defined per page via Next.js `metadata` export
- Robots: `index: true, follow: true` on public pages
- Heading hierarchy: one `<h1>` per page, sequential `h2` → `h3`
- Sitemap: `src/app/sitemap.ts`
- Images: descriptive alt text (not "image" or filename)

---

## 12. Accessibility Baseline

- Contrast: all text pairs meet WCAG AA (4.5:1 body, 3:1 large/UI)
- Focus rings: visible on all interactive elements (never `outline: none` without replacement)
- Keyboard navigation: tab order matches visual order
- Screen readers: `aria-label` on icon-only controls
- Skip link: recommended addition for keyboard users
- Color: never the only differentiator (error states use icon + text + color)
- `prefers-reduced-motion`: Lenis and entrance animations must honor this

---

## 13. Anti-Patterns (Avoid)

- Emoji as navigation or status icons
- Raw hex values in component files (use tokens)
- Mixing Neue Haas with any other typeface on the same page
- `border-radius` values inconsistent with pill (60px) or card (16px) system
- Adding glassmorphism or heavy drop-shadows (off-brand)
- Decorative animations with no semantic meaning
- Placeholder-as-label on any form input
- `overflow: hidden` on `<body>` without Lenis guard
- Hard-coded `px` widths on containers (breaks responsive layout)
- Loading images without `width`/`height` or `fill` (causes CLS)
- `position: fixed` elements without corresponding content inset

## 14. File Conventions

```
src/
  app/
    (main)/          → Public pages (About, Services, Contact)
    (admin)/         → Admin panel
    components/      → Shared UI components
    style/           → Page-scoped CSS files
    globals.css      → Token definitions + global resets
design-system/
  MASTER.md          → This file (Global Source of Truth)
  pages/             → Page-specific overrides
```

**CSS convention:** Global tokens in `globals.css` `:root`. Component-scoped styles in `src/app/style/<page>.css`. No inline styles except dynamic values.
